# JUSTICEkz: компактная карта дела и цель обращения

## Цель

Для дела «ЭКСПЕРТ ПЛЮС» пользователь должен быстро понимать, что уже установлено по документам, какие даты нужно подтвердить, где видны возможные нарушения и какой результат можно поручить системе подготовить. Глубокий разбор и подготовка проекта начинаются только после фиксации цели клиента.

## Рабочий сценарий

1. После завершения обработки документов система показывает короткую карту дела: тип спора, предполагаемые стороны, обязательства, требования, ключевые события и текущий процессуальный блок.
2. Каждая дата имеет статус: `подтверждено`, `предложение по документу` или `не установлено`. Выводы из имён файлов и эвристик не выдаются за доказанные факты.
3. Под картой дела система показывает компактные группы: нарушения/проблемы, риски, варианты действий и недостающие документы. Большие списки свернуты.
4. В чате появляется шаг «Какой результат нужен?»: быстрые цели для типового спора с ЧСИ и свободное описание цели.
5. После подтверждения цели цель сохраняется в памяти дела. Ответы чата и экспорт используют её как приоритет.
6. Для целей «дополнительные требования», «новое заявление» и «иск об оспаривании долга» система формирует доказательственный каркас проекта: адресат/суд, стороны, предмет, хронология, основания, требования, приложения и поля, требующие проверки.

## Компоновка

- Левая колонка: короткий список дел.
- Центр: компактная карта дела сверху и чат в отдельном ограниченном окне.
- Нижняя часть центральной области: закреплённый композер и статус обработки.
- Правая колонка: свернутые панели «Документы», «Даты», «Проверить», «Источники», «Задачи».
- Список документов по умолчанию показывает счётчики и предупреждения, а не все файлы; подробный список открывается по запросу.

## Ограничения

- Не показывать скрытую цепочку рассуждений модели.
- Не формировать категоричный юридический вывод без источника и подтверждения факта.
- Память цели и отчёт привязаны к `case_id`; дела не смешиваются.
- Поля проекта документов маркируются как «подтвердить», если в памяти дела нет достаточного основания.
